    How it works

    The full pipeline lives in ml/build_model.py

    1. Movie dataset133 Indian & international films with genres, director, cast, keywords and plot.
    2. Clean dataDrop duplicates, trim spaces, fix genre casing, fill missing values.
    3. Combine metadataMerge features into one “tags” text. Names are joined (aamirkhan) and important fields repeated for weight.
    4. Vectorize textTF-IDF turns each movie's tags into a numeric vector; rare, specific words get higher weight.
    5. Cosine similaritySimilarity = cos θ = (A·B) / (‖A‖‖B‖). 1 means identical direction, 0 means nothing in common.
    6. RecommendSort by similarity, skip the movie itself, return the top 10 with the reasons they matched.

    Built with Python (pandas, scikit-learn) and vanilla JavaScript. Posters from Wikipedia. Ratings are approximate. Personal project.
